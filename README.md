# Data Analysis Projects – SQL & Python

Portfolio of data analysis projects completed as part of the DataCamp **Data Analyst in Python**, **Associate Data Analyst in SQL** and **Associate Data Engineer in SQL** tracks. Each project answers a business question with real-world data and ends with clear, data-backed conclusions.

| # | Project | Tools | Key question |
|---|---------|-------|--------------|
| 01 | [Exploring London's Travel Network](01-london-travel-network/notebook.ipynb) | SQL (Snowflake) | How do Londoners travel, and how did COVID-19 affect the Tube? |
| 02 | [Motorcycle Part Sales](02-motorcycle-part-sales/notebook.ipynb) | SQL (PostgreSQL) | What is the wholesale net revenue by product line, month and warehouse? |
| 03 | [Analyzing Crime in Los Angeles](03-la-crime-analysis/notebook.ipynb) | Python (pandas, Seaborn) | When and where do crimes happen, and who are the victims? |
| 04 | [Men's vs Women's Soccer – Hypothesis Testing](04-soccer-hypothesis-testing/notebook.ipynb) | Python (pandas, SciPy) | Are more goals scored in women's World Cup matches than in men's? |
| 05 | [International Students' Mental Health](05-student-mental-health/notebook.ipynb) | SQL (PostgreSQL) | Does length of stay affect depression and acculturative stress? |

## Skills shown
- **SQL:** aggregations, filtering, `GROUP BY`, date functions, rounding and ordering, in PostgreSQL and Snowflake
- **Python:** data cleaning and transformation with pandas, binning with `pd.cut`, data visualization with Matplotlib and Seaborn
- **Statistics:** normality testing (Shapiro-Wilk), non-parametric hypothesis testing (Mann-Whitney U)
- **Communication:** turning results into business conclusions and recommendations
